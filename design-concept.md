# Design concept — ФотоСтудия Махновского в Оленегорске

## Client / project

- Name: ФотоСтудия Махновского в Оленегорске
- Date: 2026-11-25
- Niche: локальная фотостудия + печать/полиграфия + сувениры + реставрация фото
- Concept-ID: 2026-11-25-fsm-ol-product-theater-v1
- Composition-archetype: product-theater
- Forbidden-for-this-niche: fashion black-portfolio; quiet-luxury black/cream/gold; cream+#F4F1EA+terracotta; purple/indigo gradients; hero + 3 equal feature cards; megacorp print-shop UI; клон Brooklyn Editions cream-museum
- Delta-from-previous: n/a (first concept)

## Niche fingerprint

- Ритуал: принести фото/файл → напечатать, сделать сувенир или восстановить → забрать в студии на Парковой
- Материалы: фотобумага, холст, керамика кружки, магнит, спираль календаря, старое семейное фото
- Место / свет: городская студия Оленегорска; дневной предметный свет на товары
- Vernacular: «на память», «на заказ», «реставрация», прайс, макет, календарь трио
- Сенсорика: глянец отпечатка, вес сувенира в руке, шорох перелистывания календаря

## Unique thesis

1. Mood: городская фотолаборатория «на память» — практично, тепло, вещь в руках
2. Type rationale: script только внутри лого-seal; UI/заголовки — геометрический sans (Golos Text) как на VK-cover; без Inter/Roboto и без огромного editorial serif, который бьётся с script-лого
3. Palette logic: navy `#0A2342` и белый из лого/cover; холодная бумага `#F2F4F7` (не cream `#F4F1EA`); точечный акцент `#C62828` из badge; без gold
4. Composition: product-theater — full-bleed navy сцена, лого seal hero-level, доминанта = физический продукт (календарь / кружка)
5. Motion: появление seal, лёгкий сдвиг продукта, раскрытие четырёх направлений по скроллу
6. Main gesture: «фото становится вещью»

## Anti-clone checklist

- [x] Carryover: не filmstrip-process / Alumni+Onest / mid-restore (СНОВА НОВОЕ) — другой archetype, navy, Golos Text
- [x] Benchmark clone: у Brooklyn Editions берём только craft (фото работы, пейсинг, upload-path), не cream/museum палитру, не их сетку/тип
- [x] AI clusters: не purple-gradient / cream+terracotta / broadsheet / dark SaaS neon
- [x] Brand test: без лого всё ещё локальная фото+печать+сувениры (календарь, кружка, реставрация) — не «любой бизнес»

## Palette + type

- Palette:
  - `--navy: #0A2342` (лого + VK cover)
  - `--paper: #F2F4F7` (холодная бумага)
  - `--ink: #0B1220`
  - `--mist: #C5CDD8`
  - `--accent: #C62828` (точечно)
  - `--white: #FFFFFF`
- Type: Golos Text (заголовки + тело, вес 400–800); логотип — растровый/SVG seal с VK, script не дублировать в UI
